## 📖 简介

Lawyer Skill 是一款面向中国法律领域的专业 AI 助手 Skill，提供法律法规查询、案例分析、合同审查、法律意见书起草、行为可行性评估等法律服务。

### 核心原则：每一句话有法可依

- ✅ **引用具体法条** — 明确指出所依据的法律名称、条款编号
- ✅ **标注法律效力** — 区分法律、行政法规、司法解释、部门规章
- ✅ **确认时效性** — 确保引用的是现行有效法律
- ✅ **联网验证** — 对不确定的法律规定进行实时验证

## 💡 功能示例

### 1. 法律法规检索

**输入：**
```
劳动合同法关于经济补偿金是怎么规定的？
```

**输出：**
```
【法律】《中华人民共和国劳动合同法》（2012年修正）

第47条："经济补偿按劳动者在本单位工作的年限，
每满一年支付一个月工资的标准向劳动者支付。
六个月以上不满一年的，按一年计算；
不满六个月的，向劳动者支付半个月工资的经济补偿。"

【要点说明】
1. 计算标准：每满1年 = 1个月工资
2. 不满1年：满6个月按1年算，不满6个月按0.5年算
3. 工资基数：离职前12个月的平均工资

【关联法条】
- 第87条：违法解除的赔偿金为2倍经济补偿金
```

### 2. 合同审查

**输入：**
```
请帮我看看这份借款合同：
"借款金额10万元，月利率2%，借期1年，逾期按日千分之五支付违约金"
```

**输出：**
```
【合同审查报告】

【条款1】利率条款（月利率2%）
- 问题：⚠️ 可能超过法定上限
- 法律依据：
  【司法解释】《关于审理民间借贷案件适用法律若干问题的规定》第25条：
  "双方约定的利率超过合同成立时一年期LPR四倍的除外"
- 当前LPR四倍约为14.6%，您的约定24%超出约9.4%
- 风险提示：超出部分不受法律保护

【条款2】违约金条款（日千分之五）
- 问题：❌ 违约金过高
- 法律依据：【法律】《民法典》第585条
- 修改建议：建议改为"按未还金额的日万分之五计算"
```

### 3. 行为可行性评估 ⭐

**输入：**
```
我想在网上卖自制食品，合法吗？
```

**输出（第一轮 - 提问）：**
```
【行为理解】您计划通过网络渠道销售自制食品。

【初步法律定性】
该行为可能涉及以下法律领域：
1. 食品安全法 — 原因：自制食品销售属于食品生产经营活动
2. 电子商务法 — 原因：通过网络销售涉及电商经营规范

【法律依据】《食品安全法》第35条：
"国家对食品生产经营实行许可制度。从事食品生产、食品销售、
餐饮服务，应当依法取得许可。"

为了更准确地评估，我需要了解：
1. 您打算在哪个平台销售？（淘宝、微信朋友圈、抖音等）
   【法律意义】不同平台的监管要求和责任承担不同
2. 您销售的食品是什么类型？（烘焙、卤味、饮品等）
   【法律意义】不同食品类别对许可要求不同
```

**输出（最终 - 评估报告）：**
```
═══════════════════════════════════════
        行为可行性法律评估报告
═══════════════════════════════════════

【可行性判断】
  ✅ 可行部分：小规模食品生产经营可适用"三小"管理条例
  ⚠️ 需要注意：需办理营业执照
  ❌ 不可行部分：无食品生产经营许可不得销售需许可的食品

【法律风险清单】
| 风险等级 | 风险描述 | 法律依据 | 可能后果 |
|---------|---------|---------|---------|
| 高 | 无证经营食品 | 《食品安全法》第122条 | 罚款5-10万元 |
| 中 | 未办理营业执照 | 《电子商务法》第76条 | 可处1万元以下罚款 |

【合规建议】
1. 办理个体工商户营业执照
2. 咨询当地市场监管局是否适用"三小"备案管理
═══════════════════════════════════════
```

```

```

**示例：**
```
【法律依据】《中华人民共和国民法典》第509条第1款：
"当事人应当按照约定全面履行自己的义务。"
```

## 📞 常见问题

### Q1: Lawyer Skill 能替代律师吗？

**不能**。Lawyer Skill 是法律信息查询和初步分析工具，可以帮您了解法律规定、识别风险，但不能替代专业律师的案件策略制定、证据收集指导、庭审代理等服务。

### Q2: 为什么有时需要多次对话才能得到答案？

特别是使用 `+legal-assess` 功能时，AI 需要通过提问收集关键信息。这是因为法律分析需要具体事实支撑，不同细节可能导致完全不同的法律定性。

### Q3: 如何确认法律依据是最新的？

Lawyer Skill 会在以下情况自动联网验证：
- 涉及2020年后的新法新规
- 涉及司法解释的最新修订
- 用户明确要求查询"最新规定"

您也可以明确说"请联网查询最新规定"。

### Q4: 可以查询其他国家的法律吗？

当前版本的 Lawyer Skill 主要聚焦**中国法律**（含大陆及港澳台地区）。如需查询其他国家法律，建议咨询该国专业律师。
