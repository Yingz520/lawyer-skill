# +search-law 法律法规检索

## 功能说明
检索现行有效的中国法律法规，返回具体法条内容。

## 使用场景
- 查询特定法律的具体条款
- 了解某领域的法律规定
- 验证法律条文的现行有效性

## 工作流程

### 1. 确定检索范围
根据用户需求确定：
- 法律领域（民法、刑法、商法、劳动法等）
- 具体法律名称
- 条款编号（如有）

### 2. 联网检索
使用 WebSearch 查询：
```
WebSearch: "法律名称 第X条 现行有效"
```

### 3. 验证来源
优先使用以下权威来源：
- 国家法律法规数据库 (flk.npc.gov.cn)
- 全国人大官网
- 最高人民法院官网
- 司法部官网

### 4. 输出格式
```
【法律】《法律名称》（施行日期：XXXX年XX月XX日）
第X条：【条文内容】

【立法目的/要点说明】

【关联法条】
- 《相关法律》第X条
```

## 示例

### 查询合同履行规定
**用户提问**：合同一方不履行义务怎么办？

**检索过程**：
1. WebSearch: "民法典 合同履行 第509条 现行有效"
2. 验证来源：国家法律法规数据库

**输出结果**：
```
【法律】《中华人民共和国民法典》（2021年1月1日施行）

第509条第1款："当事人应当按照约定全面履行自己的义务。"
第509条第2款："当事人应当遵循诚信原则，根据合同的性质、目的和交易习惯履行通知、协助、保密等义务。"

第577条："当事人一方不履行合同义务或者履行合同义务不符合约定的，应当承担继续履行、采取补救措施或者赔偿损失等违约责任。"

【要点说明】
1. 合同履行应当全面、适当
2. 违约方需承担违约责任
3. 守约方可要求继续履行或赔偿损失

【风险提示】
具体违约责任需结合合同约定和实际损失确定，建议咨询专业律师。
```

## 注意事项
1. 必须确认法律现行有效
2. 注意法律的施行日期和适用范围
3. 区分强制性规定和任意性规定
4. 地方性法规需注明适用地区
