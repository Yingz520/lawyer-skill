# +legal-opinion 法律意见书

## 功能说明
起草专业法律意见书，对特定法律问题出具书面意见。

## 使用场景
- 重大决策前的法律论证
- 投资并购尽职调查
- 合规性审查
- 诉讼策略分析

## 法律意见书结构

```
【法律意见书】

致：XXX

关于：XXX事项的法律意见书

一、引言
   1.1 委托情况
   1.2 审查材料
   1.3 法律依据
   1.4 声明与限制

二、事实背景
   （根据委托方提供的材料整理）

三、法律分析
   3.1 问题一：...
       【法律依据】
       【分析意见】
   
   3.2 问题二：...
       【法律依据】
       【分析意见】

四、结论意见

五、风险提示

六、建议

律师：XXX
日期：XXXX年XX月XX日
```

## 写作规范

### 1. 事实陈述
- 基于委托方提供的材料
- 注明信息来源
- 不确定的事实需特别说明

### 2. 法律分析
- 每个结论必须有法律依据
- 引用具体法条
- 区分确定意见和倾向性意见

### 3. 风险提示
- 法律不确定性
- 证据不足的风险
- 对方抗辩的可能性

## 工作流程

1. **了解委托事项** → 明确法律问题，收集背景材料
2. **法律检索** → WebSearch 检索法律规定和类似案例
3. **分析论证** → 适用法律分析 + 案例参考 + 风险评估
4. **起草意见书** → 按规范格式撰写，每条意见附法律依据
