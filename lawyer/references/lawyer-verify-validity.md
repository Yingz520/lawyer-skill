# +verify-validity 法律法规有效性验证

## 功能说明
验证法律法规、司法解释的现行有效性，确认是否被废止或修订。

## 使用场景
- 确认引用的法条是否现行有效
- 检查法律是否已被修订
- 验证司法解释的时效性

## 验证方法

### 1. 联网查询
使用 WebSearch：
```
"法律名称 现行有效 2024"
"法律名称 废止"
"法律名称 修订 最新"
```

### 2. 权威来源
- 国家法律法规数据库 (flk.npc.gov.cn)
- 全国人大官网法律草案栏目
- 国务院法制办网站

### 3. 验证要点
- 施行日期
- 废止日期
- 修订历史
- 替代关系

## 输出格式

```
【有效性验证报告】

法规名称：

【当前状态】现行有效 / 已废止 / 已修订

【基本信息】
- 制定机关：
- 施行日期：
- 最新修订：

【效力变迁】
- 原始版本：XXXX年XX月XX日施行
- 第X次修订：XXXX年XX月XX日
- 废止情况：（如适用）

【现行版本】
- 法规名称：（如有变更）
- 施行日期：
- 条文变动：

【验证来源】
- 来源网站：
- 查询日期：
```

## 常见法律时效性注意事项

### 《民法典》相关
- 2021年1月1日施行
- 同时废止《婚姻法》《继承法》《民法通则》等9部法律

### 劳动法律
- 《劳动合同法》2008年施行，2012年修正
- 注意地方性规定的差异

### 公司法律
- 《公司法》2023年12月29日修订，2024年7月1日施行
- 注意新旧法衔接问题

## 示例

### 验证《合同法》有效性

**查询**：WebSearch "合同法 废止 民法典"

**输出**：
```
【有效性验证报告】

法规名称：《中华人民共和国合同法》

【当前状态】已废止

【基本信息】
- 制定机关：全国人民代表大会
- 原施行日期：1999年10月1日
- 废止日期：2021年1月1日

【效力变迁】
- 1999年3月15日通过
- 1999年10月1日施行
- 2021年1月1日因《民法典》施行而废止

【替代法规】
《中华人民共和国民法典》合同编（第三编）
- 施行日期：2021年1月1日
- 条文范围：第463条至第988条

【实务提示】
2021年1月1日后发生的合同纠纷，应适用《民法典》合同编，不再适用原《合同法》。
```
