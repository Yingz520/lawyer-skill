# +search-case 案例检索

## 功能说明
检索类似案例和判例，分析判决要旨和裁判规则。

## 使用场景
- 了解类似案件的裁判结果
- 分析法院的裁判思路
- 评估案件胜诉可能性
- 寻找有利的裁判规则

## 案例来源

### 官方渠道
- 中国裁判文书网 (wenshu.court.gov.cn)
- 最高人民法院指导案例
- 最高人民法院公报案例
- 各高级人民法院参考性案例

### 检索方式
使用 WebSearch：
```
"关键词 裁判文书网 判决书"
"关键词 指导案例 最高人民法院"
"关键词 公报案例"
```

```
二、检索结果

【案例1】XXX诉XXX案
- 案号：
- 审理法院：
- 裁判日期：
- 裁判结果：
- 裁判要旨：
- 法律依据：

【案例2】...

三、裁判规则总结
1. 
2. 
3. 

四、对本案的参考价值

【免责声明】案例仅供参考，具体案件结果因事实差异可能不同。
```

## 注意事项
1. 注意案例的时效性，优先参考近期案例
2. 关注案例的法院层级，最高法案例效力最高
3. 注意案件事实的差异性
4. 指导性案例具有参照效力

## 示例

### 检索劳动争议案例

**检索词**："违法解除劳动合同 赔偿金 2N 裁判文书网"

**输出示例**：
```
【案例检索结果】

【案例1】张某诉某公司劳动争议案
- 案号：（2023）京01民终XXXX号
- 审理法院：北京市第一中级人民法院
- 裁判日期：2023年X月X日
- 裁判结果：用人单位违法解除劳动合同，支付赔偿金

【裁判要旨】
用人单位以劳动者严重违反规章制度为由解除劳动合同，应当举证证明：
1. 规章制度经过民主程序制定；
2. 规章制度已向劳动者公示；
3. 劳动者确实存在严重违纪行为。

【法律依据】
【法律】《劳动合同法》第39条、第87条

【对本案的参考价值】
本案如用人单位无法证明规章制度制定程序的合法性，可能被认定为违法解除。
```
