# +contract-review 合同审查

## 功能说明
审查合同条款的合法性、完整性和风险点，提供修改建议。

## 使用场景
- 审查合同草案
- 识别合同风险
- 谈判前的法律准备
- 合同修改建议

## 审查维度

### 1. 主体资格审查
- 签约方是否具备民事行为能力
- 特殊行业是否具备相应资质
- 代理人是否有合法授权

### 2. 合同形式审查
- 是否采用书面形式（法律规定必须书面的合同）
- 签字盖章是否完整
- 附件是否齐全

### 3. 核心条款审查

#### 标的条款
- 标的是否明确、合法
- 数量、质量、规格是否清晰
- 验收标准是否明确

#### 价款/报酬条款
- 金额是否明确
- 支付方式是否约定
- 税费承担是否明确

#### 履行条款
- 履行期限是否明确
- 履行地点是否约定
- 履行方式是否清晰

#### 违约责任条款
- 违约金是否过高/过低
- 损失赔偿范围是否明确
- 免责条款是否合法

#### 争议解决条款
- 管辖约定是否明确
- 仲裁/诉讼选择是否恰当
- 法律适用是否正确

### 4. 特殊条款审查
- 保密条款
- 知识产权条款
- 不可抗力条款
- 合同变更解除条款

## 工作流程

1. **识别合同类型** → 买卖/租赁/借款/劳动/服务/其他
2. **确定适用法律** → WebSearch 查询相关法律规定
3. **逐项审查** → 对照法律规定检查必备条款
4. **输出报告** → 按格式输出审查意见，每条附法律依据

## 示例

### 审查借款合同

**审查要点**：
1. 利率是否超过法定上限
2. 是否有担保条款
3. 还款期限是否明确
4. 逾期利息约定

**法律依据检索**：
- WebSearch: "民间借贷利率上限 2024 现行规定"
- WebSearch: "民法典 借款合同 第680条"

**输出示例**：
```
【条款审查】利息条款
- 原文："月利率2%"
- 问题：利率约定可能超过法定上限
- 法律依据：
  【法律】《最高人民法院关于审理民间借贷案件适用法律若干问题的规定》（2020修正）第25条：
  "出借人请求借款人按照合同约定利率支付利息的，人民法院应予支持，但是双方约定的利率超过合同成立时一年期贷款市场报价利率四倍的除外。"
- 修改建议：建议修改为"按照合同成立时一年期LPR的四倍计算"
- 风险提示：超过法定上限的利息约定不受法律保护
```
