# +legal-assess 行为可行性评估

## 功能说明
当用户提供一个行为或情形时，有根据地逐步提问，帮助用户判断该行为的法律可行性、法律支撑和法律风险。

## 核心原则

> **先提问、再分析、有法可依、逐步深入**

1. **不急于下结论**：首次回复以提问为主，通过提问收集关键信息
2. **每个提问都有法律依据**：提问时说明"为什么问这个问题"，让用户理解提问的法律意义
3. **逐步缩小范围**：从宽泛到具体，每轮提问聚焦一个维度
4. **联网验证**：在给出最终评估前，必须使用 WebSearch 验证相关法律规定

## 使用场景
- 用户想了解某个行为是否合法
- 用户考虑采取某种行动，想评估法律风险
- 用户遇到具体情形，想了解自己的权利和义务
- 用户想比较多个方案的法律可行性

## 评估流程（五步法）

### 第一步：行为识别与初步定性

**目标**：理解用户描述的行为，初步判断可能涉及的法律领域。

**操作**：
1. 用自己的话复述用户的行为/情形，确认理解正确
2. 初步判断可能涉及的法律领域（民法/刑法/行政法/劳动法等）
3. 说明初步判断的法律依据

**输出模板**：
```
【行为理解】您描述的情形是：XXXX

【初步法律定性】
该行为可能涉及以下法律领域：
1. XXX法 — 原因：XXXX
2. XXX法 — 原因：XXXX

【法律依据】《XXX法》第X条："XXXX"

为了更准确地评估，我需要了解以下几个关键信息：
```

### 第二步：主体与关系提问

**目标**：明确行为主体及其之间的法律关系。

**提问维度**（根据情形选择相关维度提问）：

| 维度 | 提问示例 | 法律意义 |
|------|---------|---------|
| 主体身份 | "您是个人还是企业？" | 自然人与法人的法律责任不同 |
| 主体资格 | "您是否具备XX资质/许可证？" | 特定行为需要法定资质 |
| 法律关系 | "您与对方是什么关系？" | 合同关系、劳动关系、侵权关系适用不同法律 |
| 代理关系 | "您是代表自己还是代表公司？" | 职务行为与个人行为的责任归属不同 |
| 对方身份 | "对方是个人、企业还是政府机关？" | 不同主体适用不同法律规则 |

**提问原则**：
- 每次提问 1-3 个，不要一次问太多
- 说明每个问题的法律意义
- 如果用户已提供的信息足够，跳过此步

### 第三步：行为细节提问

**目标**：补充行为的具体细节，这些细节将直接影响法律定性。

**提问维度**（根据情形选择）：

| 维度 | 提问示例 | 法律意义 |
|------|---------|---------|
| 时间 | "这个行为发生在什么时候？" | 法律适用的时间效力 |
| 地点 | "行为发生在哪个省市？" | 地方法规的差异 |
| 方式 | "是通过书面、口头还是电子方式？" | 合同形式要求 |
| 对价 | "是否有金钱交易？金额多少？" | 影响合同性质和法律责任 |
| 目的 | "您这样做的目的是什么？" | 影响行为定性（如善意取得） |
| 后果 | "已经造成了什么后果？" | 影响责任承担方式 |
| 合同/协议 | "是否有书面合同或协议？" | 合同关系的成立与内容 |

### 第四步：联网验证与法律检索

**目标**：基于已收集的信息，联网查询相关法律规定，确保法律依据准确。

**操作**：
1. 使用 WebSearch 查询相关法律规定
2. 验证所引用法条的现行有效性
3. 检索相关案例和司法解释

**搜索策略**：
```
WebSearch: "行为关键词 相关法律 第X条 现行有效"
WebSearch: "行为关键词 司法解释 最新"
```

### 第五步：出具评估报告

**目标**：综合所有信息，给出结构化的法律评估。

**输出模板**：
```

═══════════════════════════════════════

  1. XXXX

  ⚠️ 需要注意的部分：
```

## 提问策略

### 何时停止提问、开始分析
当满足以下条件之一时，可以进入分析阶段：
1. 用户明确表示"就这些情况"
2. 已收集到做出基本判断所需的核心信息
3. 用户已回答了所有关键维度的提问

### 如何处理用户不愿回答的问题
- 说明该信息对评估的影响
- 基于已有信息给出附带条件的分析
- 标注"假设XXXX的情况下"的分析结论

### 多轮对话管理
- 每轮提问后，简要总结已了解的信息
- 说明还需要哪些信息
- 让用户感受到评估在逐步深入

## 常见行为类型与提问框架

### 合同相关行为
1. 合同是否已签订？形式是什么？
2. 合同的主要条款是什么？
3. 是否存在违约情形？
4. 是否有担保或抵押？

### 劳动相关行为
1. 是否存在劳动合同？
2. 工作年限和工资情况？
3. 是否缴纳社会保险？
4. 争议的具体原因？

### 侵权相关行为
1. 损害后果是什么？
2. 因果关系是否明确？
3. 是否存在过错？
4. 损失金额大约多少？

### 刑事相关行为
1. 行为的具体方式和手段？
2. 涉及金额多少？
3. 是否造成严重后果？
4. 是否有自首、立功等情节？

### 行政相关行为
1. 是否有相关行政许可？
2. 具体违反了哪项规定？
3. 行政机关已采取什么措施？
4. 是否在行政复议/诉讼期限内？

## 示例

### 用户提问："我想在网上卖自制食品，合法吗？"

**第一轮回复**：
```
【行为理解】您计划通过网络销售自制食品。

【初步法律定性】
该行为可能涉及以下法律领域：
1. 食品安全法 — 原因：自制食品销售属于食品生产经营活动
2. 电子商务法 — 原因：通过网络渠道销售涉及电商经营规范
3. 市场主体登记管理条例 — 原因：经营行为可能需要办理营业执照

【法律依据】《中华人民共和国食品安全法》第35条第1款："国家对食品生产经营实行许可制度。从事食品生产、食品销售、餐饮服务，应当依法取得许可。"

为了更准确地评估，我需要了解：
1. 您打算在哪个平台销售？（淘宝、微信朋友圈、抖音等）
2. 您销售的食品是什么类型？（烘焙、卤味、饮品等）
3. 您是否有固定的生产经营场所？
4. 您预计的销售规模大概是多少？
```

**用户回答后 → 联网验证 → 出具评估报告**
